## Workflow development

Prerequisite: install the `dmaf` binary, with any supported harness installed (opencode / claude / zcode / cursor / gemini / codex / dsh).

```bash
dmaf install                       # auto-detect local harness directories and deploy agents/skills (or --harness <name>)
dmaf doctor --harness opencode     # health check: layout / artifacts / asset sync / reference integrity / manifest compatibility
```

Then open your harness and start a workflow definition in one sentence, e.g. "/create-workflow create a software development workflow with requirements analysis, design, and coding stages". If you already have a written process document, "/create-workflow turn this process document into dmaf definitions" works too.
